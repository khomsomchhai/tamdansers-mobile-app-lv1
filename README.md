# tamdansers_app

## Level 1: UI, Layout & Local Data (Static Prototype)

During **Level 1**, the primary focus was on designing and developing the complete **User Interface (UI)** and **application layout** for the Tamdansers School Management System. The application includes a full authentication flow consisting of **Splash Screen, Role Selection, Login, Sign Up, OTP Verification, Forgot Password,** and **Reset Password** screens.

The application was built with a **responsive layout**, ensuring a smooth user experience across different mobile screen sizes.

### User Roles

The application supports **three user roles**, each with its own dedicated dashboard and features.

#### Student

The Student Dashboard provides quick access to essential academic information, including:

* Class Schedule
* Attendance
* Homework
* Academic Results
* School Announcements
* Notifications
* Personal Profile

The interface is designed to help students easily access their daily learning activities and school information.

#### Teacher

The Teacher Dashboard is designed to simplify classroom management through features such as:

* Class Management
* Student Attendance
* Homework Management
* Score Management
* Assignment Submission Review
* Student Information Management

These features provide teachers with an organized and efficient workflow for managing their classes.

#### Parent

The Parent Dashboard enables parents to monitor their child's academic progress by providing access to:

* Attendance
* Homework
* Academic Results
* Class Schedule
* School Announcements
* Notifications
* Student Profile

This dashboard allows parents to stay informed about their child's learning activities and school updates.

### Local Data Implementation

At this stage, the application uses **Local JSON files** and **SQLite** to store and display sample data, allowing the complete application workflow to be tested without requiring a backend service.

### Technical Highlights

* Responsive UI for multiple screen sizes
* Local JSON & SQLite integration
* Custom reusable widgets
* Bottom Navigation implementation
* Reusable UI components
* Clean project structure
* Static prototype with complete user flow

Level 1 establishes the foundation of the application by delivering a fully interactive prototype with complete navigation, reusable components, and realistic sample data, making it ready for backend integration in the next development phase.
